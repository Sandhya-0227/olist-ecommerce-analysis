# olist-ecommerce-analysis
End-to-end e-commerce analytics project using Python, SQL, Excel, and Power BI on real Olist Brazilian E-Commerce data.
("The master dataset (110,832 rows) is not included in this repository due to file size. It is generated by running 01_data_exploration.py against the raw Olist dataset available on Kaggle.
Excel analysis file is not included due to file size. The analysis covers 4 pivot tables built on the master dataset — category revenue, monthly trend, delivery by state, and review distribution.")
